# NOVA — AI Productivity Platform

A modern, responsive landing page for NOVA, a fictional AI productivity platform created for the Sankar Group Front-End Development Intern assignment.

## 🚀 Live Demo

https://nova-ai-landing-page-cjj5.vercel.app

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- CSS
- Lucide React
- Vercel
- GitHub

## ✨ Features

- Responsive desktop, tablet and mobile design
- Sticky navigation bar
- Mobile hamburger menu
- Smooth scrolling navigation
- Modern hero section
- Trusted-by company section
- 6 feature cards
- AI Copilot product section
- Solutions / use cases
- Statistics section
- How-it-works section
- 3 customer testimonials
- Monthly / annual pricing toggle
- 3 pricing plans
- FAQ accordion
- Final call-to-action section
- Dark / light mode
- Demo modal
- Email validation interaction
- Hover animations
- Scroll reveal animations
- Responsive layouts without horizontal scrolling
